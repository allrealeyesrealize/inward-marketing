# inward-marketing

Rendered slide images for INtegration's TikTok photo carousels.

These are a **staging host**, not the thing TikTok reads. The chain is:

    this repo (raw URL)  ->  SocialClaw upload_asset(sourceUrl)  ->  getsocialclaw.com/media/...  ->  the post

TikTok only pulls post media from a domain verified in the posting app's
developer portal, which is SocialClaw's and not ours — so a
raw.githubusercontent.com URL used directly as a post's media would pass
validation, schedule cleanly, and then fail at publish with
`url_ownership_unverified`. Pulling each image into the SocialClaw library
first gives back a URL on a domain TikTok will accept.

Public on purpose: SocialClaw fetches these unauthenticated. Nothing here is
private — every image is destined for a public TikTok post. No app code, no
configuration, no keys.

Generated by `node slides.js` in the private product repo from
`slides-decks.js`. Do not hand-edit; regenerate instead.
